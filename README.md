# Portfolio EKOH ETSIN

Portfolio personnel développé avec HTML, CSS et JavaScript.

## Structure du projet

- `index.html` : structure principale du site
- `css/style.css` : styles globaux et responsive design
- `js/script.js` : scripts JavaScript
- `assets/` : images, icônes et autres ressources

## Objectif

Présenter le profil professionnel, les compétences, les projets et les coordonnées de contact.
